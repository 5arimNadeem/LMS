useRefreshTokenQuery is auto-generated by Redux Toolkit Query (RTK Query) — it's not something you defined manually.

How it's generated
When you call createApi({...}) at apiSlice.ts:4, RTK Query looks at each endpoint you defined in the endpoints builder and automatically creates a React hook for it.

The naming convention is:

builder.query(...) → use<EndpointName>Query
builder.mutation(...) → use<EndpointName>Mutation
So because you defined refreshToken: builder.query({...}) at apiSlice.ts:18, RTK Query generates useRefreshTokenQuery (the r gets capitalized → RefreshToken). Same logic gives you useLoadUserQuery from the loadUser endpoint at apiSlice.ts:38.

Where it's exported
At apiSlice.ts:61:


export const { useRefreshTokenQuery, useLoadUserQuery } = apiSlice;
You're destructuring the auto-generated hooks off the apiSlice object that createApi returned, then re-exporting them so the rest of the app can import them.

Where the type comes from
The TypeScript types for these hooks come from @reduxjs/toolkit/query/react (imported at apiSlice.ts:1). The createApi return type is generic over your endpoint definitions, so TS infers the exact hook names and their argument/return types from what you passed to endpoints.
